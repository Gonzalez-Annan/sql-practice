# SQL Practice

A collection of SQL practice queries, organised by topic. Each folder contains short, self-contained scripts focused on one concept.

## Topics

| Folder | What it covers |
| --- | --- |
| `basics` | Simple SELECT queries |
| `filtering` | WHERE, BETWEEN, IN, LIKE, ORDER BY, LIMIT |
| `aggregation` | COUNT, SUM, MIN/MAX, GROUP BY, HAVING |
| `case_when` | Conditional logic with CASE expressions |
| `joins` | Inner, left and self joins |
| `subqueries` | Nested and correlated subqueries |
| `set_operations` | UNION and related operators |
| `string_functions` | Text manipulation |
| `date_functions` | Working with dates |
| `null_handling` | COALESCE and NULL logic |
| `window_functions` | Ranking, running totals and averages |
| `views` | Creating and using views |
| `indexes` | Index creation |
| `constraints` | Table constraints |
| `transactions` | Transaction control |
| `database_design` | Schema design |
| `advanced` | More complex queries |
| `challenges` | Numbered practice problems |
| `datasets` | Sample data used by the queries |

## Running the queries

The scripts were written for DATABASE_NAME. Load the sample data from `datasets/` first, then run any script on its own.

## About the commit history

These scripts were written between November 2025 and May 2026 and added to git afterwards. Commit dates are approximate.
